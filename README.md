# First Repo

1. for the first commi/creation of a repository, you must initialize the repo.
2. stage any changes made, using the '+' in source control next to changes section
3. commit staged files, with descriptive message. This permanently saves a version of your code to your local repo.
4. Push changed to github (or publish repository if this is first commit/save)


-- staging files - you have made changes and you want to possibly save them permanently as a version.
-- commit files - you give a name to the version you are permanently saving.
    -- make sure the message is descriptive.
